# Batch Compress Video

**Batch Compress Video** is a Windows desktop app by [3thousand30](https://3thousand30.com) for compressing batches of common video files locally. It writes your chosen MP4 or WebM format to a separate output folder, so your originals stay untouched.

[Get it on Microsoft Store](https://apps.microsoft.com/detail/9MXZ6FLXKHJF){: .btn .btn-blue }

Point it at a folder. Choose quality, speed, audio bitrate, and output format. Select where the results go, then compress the batch.

---

## How it works

1. **Select your input folder** — choose a folder containing supported video files
2. **Choose compression settings** — set the quality level, encoding speed, audio bitrate, and output format
3. **Confirm the output settings** — choose the output folder, optional filename suffix, and collision behaviour
4. **Compress the folder** — BCV writes the selected format and shows per-file progress plus a final size summary

Video processing happens locally on your device through the FFmpeg engine bundled with the app. Your videos are not uploaded to a server.

---

## Key features

- **Batch compression** — process every supported video in one folder
- **Output format choice** — MP4 (H.264/AAC) for broad compatibility or WebM (VP9/Opus) for web delivery
- **Quality control** — set CRF from 18 to 32 to balance visual quality against file size
- **Encoding speed choices** — choose Fast, Medium, or Slow depending on how much time you can spend encoding
- **Audio bitrate control** — export audio at 128, 192, or 256 kbps
- **Safe output workflow** — originals are never overwritten; a temporary candidate is promoted only after FFmpeg succeeds
- **Skip existing files** — resume or re-run large folders without replacing output you want to keep
- **Activity logs** — review progress, skipped files, failures, and batch size results
- **Local processing** — no account, upload, telemetry, or cloud compression service
